# Panacea Mobile — Android Booking Experience | Portfolio

A concise portfolio case study of a team-built Android app for room and service discovery, booking, and booking history.

> **Portfolio reconstruction:** This repository contains a small, independently created illustration of the mobile flow with sample data. It is not the Android application, an APK, or a live booking service.

## The problem

Help customers find rooms, explore details, and follow a booking journey on mobile, including access to booking history.

## My contribution

I contributed to parts of the booking and booking-history flows, API integration, and local data handling in a collaborative project. The original app and related systems were built by a team; this case study does not claim individual ownership of the entire product.

## Explore the demo

Open [`index.html`](index.html) in a browser. The mobile-style reconstruction uses sample data, runs without an account or API, and does not make bookings or process payments. It is an illustrative walkthrough, not a copy of the original Android UI.

## Project context

The original project was a native Android app using Java/XML, Retrofit and SQLite, integrated with backend APIs. The payment flow was a coursework demo and did not process real money. Those technologies describe the original project; this independent portfolio demo is plain HTML, CSS, and JavaScript.

## What this shows

- Designing a mobile booking and history journey.
- Working with API-backed flows and local application data.
- Collaborating on a multi-platform product.
