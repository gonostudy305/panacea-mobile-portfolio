# Panacea Mobile — Android Booking Experience

A portfolio case study of a team-built native Android app for discovering rooms and services, making bookings, and viewing booking history.

## See the real interface

The [portfolio page](https://gonovn.me/panacea-mobile-portfolio/) displays an **actual screenshot of the Android app's home screen** taken with the `Demo Panacea` account. The screenshot shows a demo booking and other example content. Open the [full-size screenshot](assets/panacea-mobile-home.png) to inspect the original image.

The portfolio page is a static presentation; the screenshot itself is not interactive. It does not make bookings, connect to the original backend, or process payments.

## My contribution

I contributed to parts of the booking and booking-history flows, API integration, and local data handling. Panacea was built collaboratively; this repository highlights selected work and does not represent the entire project as my individual work.

## Original project context

The Android app was built with Java/XML, Retrofit and SQLite, and integrated with backend APIs. Its coursework payment flow was a demo and did not process real money. The source code, private configuration and Git history of the team project are not included here.

## Contents

- `index.html` — standalone portfolio page; open directly in a browser.
- `assets/panacea-mobile-home.png` — actual screenshot of the Android app using a demo account.

The page uses no external scripts, fonts, APIs or dependencies. The GitHub repository link on the page is an ordinary link to this repository.
